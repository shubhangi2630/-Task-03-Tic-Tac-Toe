# 🎮 Tic Tac Arena

A modern and interactive **Tic-Tac-Toe web application** developed by me.
The application allows users to play Tic-Tac-Toe against another player or against the computer while tracking the game state and automatically detecting winning conditions.

---

## ✨ Features

- 👥 Player vs Player mode
- 🤖 Player vs Computer mode
- ❌ X and ⭕ O gameplay
- 🏆 Automatic winner detection
- 🤝 Draw detection
- 📊 Score tracking
- 🔄 New Game option
- 🧹 Reset Score option
- ✨ Winning-cell animation
- 🎨 Modern dark/neon user interface
- 📱 Responsive design for different screen sizes
- ⚡ Interactive gameplay using JavaScript

---

## 🛠️ Technologies Used

- **HTML5** – Structure of the application
- **CSS3** – Styling, animations, and responsive design
- **JavaScript** – Game logic, user interactions, and game-state management

---

## 🎯 Task Objective

The objective of this project is to build an interactive Tic-Tac-Toe web application that:

- Handles user clicks
- Tracks the current game state
- Switches turns between players
- Checks for winning combinations
- Detects draw conditions
- Provides Player vs Player and Player vs Computer gameplay

---

## 🎮 How to Play

### Player vs Player

1. Select **Player vs Player**.
2. Player X starts the game.
3. Players take turns selecting an empty cell.
4. The first player to get three symbols in a row wins.
5. If all cells are filled without a winner, the game ends in a draw.

### Player vs Computer

1. Select **vs Computer**.
2. Player X makes the first move.
3. The computer automatically plays as O.
4. Continue playing until there is a winner or a draw.

---

## 📊 Score System

The application keeps track of the number of games won by:

- **Player X**
- **Player O**

The **Reset Score** button can be used to clear the scores.
